# Trust layer

A Trust Passport is a shareable, version-specific evidence record—not a legal certificate. It contains agreement version ID, canonicalization version, content hash and algorithm, Contract IR version, verification engine version, structural and behavioral results, unsupported clauses, human approval evidence, timestamps, and blockchain references only when chain data exists.

Changing agreement content creates a new version and invalidates prior parity evidence. The UI should show exactly which version was verified. It must distinguish content integrity, structural comparison, semantic mapping, executable behavior, and legal validity.

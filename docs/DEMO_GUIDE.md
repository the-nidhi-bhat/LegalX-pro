# Demo guide

Open `/demo`. The seeded agreement is a freelancer building a website for ₹50,000, split into ₹20,000 for design approval and ₹30,000 for delivery, with a 5-day review window and dispute freeze behavior.

The recommended story is: AI Workspace → Contract IR → Agreement detail → Parity Verification → Simulate tamper → observe score 74 and execution blocked → Restore matching logic → Smart Contracts → Milestones → Transactions → Activity.

The banner, badges, copy, and Smart Contracts page distinguish demo records and simulated integrations from real events. No wallet connection, payment, deployment, AI key, or account is required.
